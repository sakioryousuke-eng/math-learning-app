# 第5段階 カリキュラム監査

確認日：2026年9月7日。対象は中学数学および数学I・II・III・A・B・Cの主要内容。教科書順の再現や、専門学科の理数数学・大学数学の網羅性の認定ではない。データ上の対応先と固定教材の充足は区別する。

出典：文部科学省の現行解説掲載ページから数学編を確認した。[中学校数学編](https://www.mext.go.jp/component/a_menu/education/micro_detail/__icsFiles/afieldfile/2019/03/18/1387018_004.pdf)の内容構成表（PDF 15〜16ページ）、[高等学校数学・理数編](https://www.mext.go.jp/content/20260115-mxt_kyoiku02-100002620_04.pdf)の数学I〜Cの構成表（PDF 26〜27ページ）および数学Cの表現の工夫（PDF 136ページ）を中心に照合した。主要領域の対応と下記の統合方針は本実装での判断である。

主要な履修領域には対応先を用意した。監査は内容項目とDAGの確認であり、全ての授業・演習が完成したという結論にはしない。誤差・近似、空間作図、図形の中心や補助線、検定の仮定など、coverageの一部はまだ十分な固定演習や説明資料がない。

統計のシミュレーションは `src/curriculum/workbenches.ts` に、再現用seed付きの二項試行・標本比率の変動を実装した。学習カルテには触れない。画面への埋込み、正規母集団の抽出などの拡充は今後の教材整備で行う。

既存7単元のDAGとIDを保存互換のため維持した。そのため、新規DAGを含めて数学的な唯一の最短ルートであると最適性を証明したわけではない。特に中学・高校をまたぐHSXの領域表示は、履修学年とアプリのまとまりを混同しないよう、今後の教材説明で補う。
