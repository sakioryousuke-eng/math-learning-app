## 1. 復元した教育設計

コードに先立ち [教育設計正本](quadratic-function.md) を作成した。正本→検証済み教材→UIの順とする。平方完成や判別式は公式の反復ではなく、未知の問題を既知の表現へ変える道具として導入する。条件を保持した「日本語・現実⇄式⇄解」、最後に元の条件へ戻る検証を共通の軸にした。

新概念は約2分の試行提案→困難・必要性→道具→元問題への復帰。説明を見た問題は独立成功から除く。グラフの作業台を付け、表示枠と数学上の定義域を区別する。STEP5・MAXの問題には方法名や解法図を先出ししない。

## 2. 5 STEPの最終構造

1. 平方完成 → グラフ：QF-GRAPH、QF-FORM
2. 最大・最小 ＋ 定義域：QF-RANGE
3. 共有点 → 方程式 → 判別式：QF-DIFFERENCE、QF-COUNT
4. パラメータ ＋ 場合分け：QF-PARAM、QF-SIGN
5. 総合・方法指定なし：QF-INTEGRATE

## 12. 数学的検証方法

[数学監査記録](quadratic-audit.md) に各問題の独立導出を記載した。問題の一意性、正答、途中式、定義域、絶対値、±、境界、等号、場合分けの網羅・重複、不適解、前提技能、測定対象、難易度、解説の根拠の15項目を確認した。難易度については設計上の暫定評価であり、実測校正済みとはしない。

平方展開、元式への代入、極値の端点・頂点比較、根の存在と区間包含、別表現による照合を実施。独立した監査コード scripts/audit-quadratic.ts は33教材の監査済み内容照合、73パラメータ標本と恒等式・根・端点等の検算に合格した。本文・解答・図のハッシュは変更検出用であり、正しさの証明ではない。数値確認およびソフトウェアテストは、記述した数学的導出を置き換えない。

## 13. 発見した既存問題・解答の誤り

旧QFN関連22題を問題文から独立に解いた後で比較し、今回確認した範囲の答えの値には数学的誤りを発見しなかった。全410題が正しいという意味ではない。確認できた問題は、3Skillへの圧縮、方法ラベルの先出し、必要性を経ない技法提示、短い代表問題でのMAX扱いなどの教育構造上の不足だった。これを旧解答の小修正ではなく新教材へ置換した。

## 14. stable仕様

他単元にも使用できる汎用StablePolicyを導入。技能ごとの独立成功数・状況数・必須状況群・評価観点で判定する。QF-FORMは正負係数、QF-RANGEは区間外と下に開く場合、QF-COUNTは0/1/2共有点の証拠を要求する。IDが違うだけで同じ独立性キーなら重複計上しない。

方法・条件・計算・結論がすべて成功し、判読可能・独立であることを要求する。説明閲覧、同一問題の反復、部分成功は独立成功数を満たさない。失敗後の成功履歴で判定し、既得stableをMAX失敗だけで一律破棄しない。既存の教育コア関数は保持し、その手前に教材policyを適用した。

## 15. 修復仕様

1回の失敗で即修復しない既存診断を維持。反復した前提誤りから、平方完成QF-FORMや因数分解HSX2など必要な祖先Skillだけ修復する。無関係なSkill指定は履歴更新前に拒否。activeUnitを維持し、修復stable後に保存した元問題IDへ復帰する。旧未検証問題へ戻る場合は、復帰先を消さず教材確認待ちにする。

## 16. MAX仕様

独立成功3回、最初の有効成功から7日以内、1日最大1回を変更していない。新MAX3題は方法指定なし・複数小問・条件と根拠の記述を要求する。今回の仮採点経路では25分を暫定上限として接続し、超過答案は記録するがMAX成功証拠にしない。25分が模試相当として妥当かは未校正。

未検証の旧MAX答案を新たなMAX成功へ合算しない。履歴と日付は保存するため同日の再計上も避ける。移行時の取得済みMAXはユーザー指定に従い維持。初期診断合格はstableのみでMAXにはしない。仮採点の「正解」選択は実答案の能力認定ではない。

4. 他単元は未検証のため新規利用者の通常ルートが停止する。二次関数デモは専用デモ領域で前提MAXを仮設定して確認できるが、通常ルートのゲートは迂回していない。
