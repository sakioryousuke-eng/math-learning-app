# 二次関数：紙答案と選択式採点（現行の補足仕様）

ユーザーの今回の指示により、公開アプリはpaperCurriculumを使う。二次関数MAXについて本書を以前の3回・7日・1日1回の記述より優先する。旧カタログ・他単元・教育コアのMAX関数は回帰比較用に維持する。

- 紙答案が本体。通常28題と直接修復用因数分解2題は4択、MAX候補3題は6択。
- 正答はchoiceIdで判定し、順序は表示時にシャッフルする。問題文には選択肢を含めない。
- 通常の正解は最終結論の成功。方法・条件・計算は未観測を初期値とし、任意の紙答案確認は自己申告として区別して保存する。自動採点の成功とは断定しない。stableは従来の複数独立問題・状況・必要観点の証拠で判定する。
- QFN MAXは6択正解と、その問題に固有の必須チェック全項目の自己申告が揃った1回で取得。3回・7日・1日1回・25分上限で取得を阻まない。問題を紙で実戦的に解き切る目的は維持する。
- 失敗は既存stableを下げない。誤答タイプ、修復候補Skill、不足した答案要素を保存する。現時点では選択だけから前提技能不足と断定して自動修復には入れない。既存の修復中の学習は継続できる。
- 再挑戦は未使用の別候補を優先。3題使用後も直前と異なる候補へ進める。通常ユーザーと検証デモは別名前空間。
- 選択記録はAssessmentの任意拡張。既存保存データにフィールドがなくても読める。
- 初回診断は既存経路を維持し、今回の選択式採点対象には広げない。
- QF-INTEGRATE-V1-1は「壁に垂直な辺をx mとし、1≦x≦4とする」と明確化。答えは変更せず、この問題の監査済みハッシュのみ更新。
- 解説・答え・静的／動的グラフは従来の数学説明を表示し、選択肢の番号や記号を持ち込まない。

画像認識・Firebase・OpenAI APIは使用しない。紙答案の根拠や可読性を機械で読み取ったと称さない。
