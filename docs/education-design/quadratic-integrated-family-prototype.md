# 第5生成ファミリー：二次関数・総合判断

検証専用・未reviewed。`?verify=on` →「生成問題ファミリー試作5 二次関数・総合判断」。通常学習・stable・QFN MAXへは接続しない。

二次関数の生成ファミリーは本試作で5種類に区切る。以後の拡充は、安全なvariant、reviewed固定問題、実戦／MAX固定問題で行う。基礎反復はreviewed固定問題、標準〜応用反復は第1〜4、方法選択を伴う総合練習は第5、MAXは既存固定問題という役割を保つ。

## 12題

|番号|難易度|構造|生成された結論|
|---|---|---|---|
|1|標準|一般形→軸・頂点→区間内の候補比較|最大5、最小−4|
|2|標準|下向き・区間外の軸→両端比較|最大3、最小−12|
|3|応用|一般形→動く軸→最大・最小の全場合|境界k=0,3/2,3で整理|
|4|応用|指定最大値から逆にkを求める|k=−2,3|
|5|応用|共有点→正の2根→根の和の制約|2<k<3|
|6|応用|接触→接点の位置→元の座標|k=2√2、接点(√2,3)|
|7|応用|平方完成→共有点の区間→2根の距離|0≦k≦3|
|8|実戦|全xでの下限制約＋正負の根|−1≦k<0|
|9|実戦|値域の包含→最大・最小の共通条件|3/4≦k≦1+√2|
|10|実戦|固定点を通る直線→2根の半開区間|2<k<10/3|
|11|実戦|利益の最大値＋許容範囲内の損益分岐点|4≦k≦17/4|

12種類のstructure signatureを持つ。方法名を問題文に指示せず、各題で複数の判断を求める。STEP1の表現変更、STEP2の定義域と候補、STEP3の方程式化と判別式、STEP4のパラメータと境界を、STEP5の方法選択として組み合わせる。

## モデルの組合せ

上位`IntegratedQuadraticProblem`は、必要なextrema／intersection／placement／horizontalモデル、追加条件の集合、solution trace、正答、診断候補、グラフ関数、独立oracleを持つ。巨大な万能数学エンジンにはしない。

- 第1：水平線の共有点・区間モデルを第7問で共有し、第4の配置結果と照合。
- 第2：候補と場合分けを再利用。一般形から得る軸h(k)へ変数変換し、頂点の高さを加えて一般形の最大最小に接続。独立候補評価も再利用。
- 第3：放物線と直線の差・判別式・元と差のグラフを再利用。
- 第4：根配置、独立root-placement oracle、多項式不等式の集合処理、厳密境界ラベルを再利用。
- 新しい集合アダプターは、既存の区間結果の交差・和を組み合わせる部分だけ。多項式を解く処理はコピーしない。

上位問題は正答を手入力しない。固定値、場合分け、パラメータ集合、接点座標の答案型を使い、各構成モデルの出力から最終答案を生成する。

## Solution traceと解説

各導出ノードは種類・実際の計算結果・その意味を説明する日本語を保持する。解説はtraceから生成する。

例：InterpretPrompt → PreserveDomain → CompleteSquare → ReadAxis → GenerateCandidates → SplitParameterCases → CompareValues → SolveParameterCondition → IntersectConditions → VerifyOriginal → Conclude。

共有点系はEqualYValues → MoveToDifferenceEquation → ChooseDiscriminant → CheckRootPlacementなどを使う。不要なノードや技能を全問へ一律付与しない。

## 誤答と履歴

第2・第4の誤答モデルを一般形・追加条件へ接続するほか、平方完成の符号誤認、定義域省略、元条件での絞込み不足、差の接点を元の接点と誤認する答案を生成する。診断価値と同値比較で3候補を選ぶ。適用できない「場合分けの欠落」は固定パラメータ問題の候補から外す。

problemRequirementsとmistakeHypothesesを分離する。1回の選択は狭い弱点仮説であり、能力不足の確定証拠ではない。X09は必須技能にも弱点証拠にも含めない。

## グラフと独立検証

提出前はグラフ・方法名・構造分類を見せない。提出後、静的グラフ2題・動的グラフ9題を表示する。第5問は式で十分に整理できるためグラフを付けない。動的表示は内部valueとsymbolic labelを分け、境界ボタンとoracle表示を同期する。

全12題で−20〜20を0.025刻みで照合し、正答・採用誤答の境界とその前後±0.00001、±100も評価する。最大最小は元の係数と区間内候補を直接評価。共有点・根配置は実根を計算し、テスト側に記述した元条件へ直接代入する。平方完成・軸・頂点・端点値・同値な差・D・各場合の被覆・元条件への復帰を該当問題ごとに検査する。
