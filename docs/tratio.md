# 新TRATIO 第1段階

## 教育設計

旧TRATIOの例題・解説・Skill名は教育設計の根拠にしない。新規ID `TR-*` の固定通常22題、対応関係の修復2題、MAX原型3題を作成した。旧データは削除せずunreviewed、旧Skillはretiredとして保持する。

|STEP|思考負荷|Skill|通常題数|
|---|---|---|---:|
|1|角を座標に対応させる|TR-UNIT → TR-RELATION|6|
|2|基準から実際の長さへ|TR-RIGHT|5|
|3|与えられた角辺から道具を選ぶ|TR-SINE / TR-COSINE → TR-AREA|8|
|4|図形と条件をつなぐ|TR-INTEGRATE|3|

角と長さを扱いたい必要性を短く示し、半径1の点をP=(cosθ,sinθ)と直接定義する。cosは横、sinは縦、tan=y/x（x≠0）。角は0〜180°に限定し、周期・三角方程式・加法定理などのTRIG内容は導入しない。単位円を長時間発見させる課題や特殊角の大量反復は置かない。

直角三角形の辺比は、単位円の三角形を相似拡大した結果として扱う。相似・三平方・平方根・円周角は既習の道具として使用する。正弦定理は対角・対辺の対応と共通の高さ、余弦定理は座標と距離、面積は底辺×高さから説明する。C=90°ではcosC=0になり、三平方が余弦定理の特殊ケースとして現れる。

解説は「考え方→解き方→図→答え」。考え方を公式名で始めない。STEP4では公式の指定をしない。MAX原型の15°・105°は加法定理を使わず、垂線と既習の三平方で長さを導く。

## 個別数学レビュー

|ID群|独立計算・確認点|
|---|---|
|UNIT 1〜3|座標の正規化、原点距離、y軸対称、象限の符号|
|RELATION 1〜3|cos90°=0とtan未定義、円の方程式、sinの2解|
|RIGHT 1〜5|直角三角形の2辺、塔の高さ、鋭角条件、垂線による二等分、2地点の共通の高さ|
|SINE 1〜3|角辺の対応、外接円半径と直径の区別、SSAの2通りと内角和|
|COSINE 1〜3|座標差の距離、3辺からの角、直角の補正項0|
|AREA 1〜2|鈍角で延長上にある高さ、面積条件を満たす2角と異なる辺|
|INTEGRATE 1〜3|対角線の両側の面積、円周角からの計量、面積・外接円・高さの照合|
|SINE REPAIR 1〜2|頂点を含まない対辺の特定。新しい公式を追加しない|
|MAX 1〜3|単位円＋SAS＋高さ＋外接円、複合図形、SSAの2形状＋垂線＋面積＋円|

`math.ts`の三角形検証は座標から距離・内積・行列式を計算し、固定の根号表現で記載した正答値と照合する。モデル・正答を同一の文章の比較で検証しない。単位円は0〜180°を0.25°刻みで、正負・対称性・二乗和・tanの比を別途確認する。SSAは角の範囲と内角和で解を選別する。

全27題に1正答＋3誤答。誤答の構造は、座標対応、逆比、符号、対辺対応、余弦定理の符号、直角でない図への三平方、高さと辺の混同、複数解の見落とし、元条件への戻し忘れなど。数値ベクトルでも選択肢の同値性を検査する。図の座標と数値ラベル、直角、円、補助線も照合する。

## 図と検証UI

再利用可能なSVGで単位円と多角形を描画する。単位円の角はスライダーと角度ボタンで動かし、P・cos・sin・tanを連動表示。90°のtanは定義しない。三角形には頂点・辺・直角・補助線・必要な円を表示する。

図を読むことが課題に含まれる場合にX09を付与し、全問一律に付けない。総合1は辺の数値を図から読む問題。problemRequirementsと選択誤答のmistakeHypothesisは別管理し、CrossSkillを失敗と即断しない。

`?verify=on` →「三角比 TRATIOの新教材を確認」でSTEP・Skill・教材区分・問題を選ぶ。提出後に解説・図・必要能力・誤答仮説・repair候補・個別検証結果を確認できる。通常・修復問題は既存の専用デモでも確認できる。MAX原型はこの画面内に限定する。

## 学習・保存・修復

通常のSkill前提・大単元解放は変更しない。新教材だけをreviewedとして通常出題に加え、旧TRATIOは除外する。確認済みの独立成功2件・2状況と既存の答案要素チェックを新Skillのstable基準に使う。

1問の誤答は仮説1件であり、即修復しない。同じ狭い仮説が、成功を挟まず直近4件以内の異なる問題で2回見られた場合にだけ該当Skillの短い確認へ進む。対辺対応は2題の専用修復を使用。activeUnitを変えず、完了後は保存した元問題へ戻す。仮説のCrossSkillを確定失敗として蓄積しない。

保存schema 1に任意のtratioEvidenceを追加。教材versionはmath-v0.7-tratio-reviewed。移行前のcheckpointを丸ごと保持し、新7Skillはunseenで追加する。旧TRATIOの中断課題・修復先は履歴に保存して新教材から再開する。未信頼の旧TRATIO MAXは新教材のMAX証拠へ流用しない。他単元のMAX、QFN履歴・90題・既存MAX・5ファミリーは維持する。

## MAX原型の扱い

3候補は数学検証済みだが、進研模試相当の難度・時間・採点者間一致の実測校正は未実施。そのため通常のMAX候補リストに加えない。検証画面で4択の結論を比較できるが、完全な紙答案の評価やMAX取得は行わない。

教育要件は、定義の理解、図の条件、角辺対応、長さ・面積、既習事項、複数段階の方法選択、全場合と元条件確認。将来の1回完全成功overrideは未実装。既存TRATIOの3回・7日・1日1回ポリシーと、QFN MAX＋TRATIO MAXの両方を必要とするTRIGゲートは変更しない。

activity-site、Firebase、OpenAI API、公開基盤は変更しない。
