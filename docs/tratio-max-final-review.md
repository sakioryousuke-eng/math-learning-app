# TRATIO 固定MAX 最終数学レビュー

対象は TR-MAX-FINAL-1〜3。旧原型は履歴・検証画面に保持し、本番候補には新IDを使う。
これは実装担当による独立した数理レビューであり、生徒による所要時間の実測ではない。

## 1 平行線・相似から面積と外接円

与条件 AB=8、AC=6、A=60°、AD=2、DE∥BC。DはAB内、EはAC内。
A=(0,0)、B=(8,0)、C=(3,3√3)、D=(2,0)、E=(3/4,3√3/4) と、原条件から直接置ける。
DE/BC=AD/AB=1/4、AE=3/2。BDEの行列式は9√3/2、面積は9√3/4。
BD=6、DE=√13/2、BE=√217/2。外心はBDの中垂線x=5とDEの中垂線の交点で、半径は√8463/18。
解説ルートは相似→高さ・面積→BE→BC→sinD→R。oracleは辺長から正弦定理を再実行せず、座標の行列式と外心で確認する。
別解：3辺と面積からR=BD·DE·BE/(4S)。∠BDEと∠ABCは補角だがsinは等しい。
候補は一意。各辺は正で三角形不等式を満たす。相似比逆転ではEが辺外へ出るため、元の条件へ戻れば排除できる。
誤答5つは、相似比逆転を最後まで伝播、BEの余弦補正符号、面積の1/2、半径と直径、BDへのAD誤転送。
答案ではAE・BD・BEと対辺対角の根拠、面積と半径の単位が必要。公式名や中間目標を問題文で指定しない。
複数の三角形と相似から一般三角形へ移る判断を主な難度とする。大きい根号の数値近似は要求しない。

## 2 二等辺台形の高さから面積と外接円

AB=8、CD=4、AD=BC=√13、AB∥DC。通常の凸な二等辺台形。
A=(0,0)、B=(8,0)、D=(2,3)、C=(6,3) と置く。左右反転・上下反転でも求める量は同じ。
水平のずれ2、高さ3。ABCの行列式は24、面積12。
ABの中垂線x=4、ACの中垂線との交点はO=(4,−1/2)。OA²=65/4、R=√65/2。
解説は生徒が垂線を選ぶ→等しいずれ→三平方→面積→対角線→sinB→R。
別解は上記の外心、または3辺と面積。退化せず、AC=3√5、BC=√13が原条件に戻る。
誤答は、斜辺を高さとして伝播、三平方で和を使って伝播、面積の1/2、直径、sinの比逆転。
高さを誤るモデルにはsinB>1などの不成立もあり、最後の元条件確認で棄却すべき典型誤りである。
問題図は四角形と与えられた長さだけ。E,F、垂線、対角線の補助線、外心は解説後。
紙答案には等しいずれの理由、三平方、面積、ACと角Bの対応を残す。単純SAS一回では解けない。
3候補の中では計算は軽くし、補助線・対角線・円へつなぐ判断で水準をそろえる。

## 3 SSAの2配置から辺・面積・半径

A=30°、BC=5、CA=5√2。A=(0,0)、C=(5√6/2,5√2/2)、Bは正のx軸上。
C中心・半径5の円と正半直線の交点は x=5(√6±√2)/2。どちらも正、互いに異なる。
面積は行列式から25(√3±1)/4。外心は各配置とも原点から距離5。角Bは45°又は135°、角Cは105°又は15°で、どちらも内角和と正角条件を満たす。
解説はsinB→補角候補→垂線と三平方→2つのAB→面積→R。
独立oracleは円×半直線の交点、行列式、垂直二等分線。解説の公式列は共有しない。
別解は候補の角CからAB=10sinC。ただし15°・105°の導出が必要で、未習の加法定理を必須にしない。
誤答は各配置の片方だけ、両方の面積1/2忘れ、直径、BCをBHに取り違えた2配置の伝播。
完全答案では候補を二つ列挙し、対応するABと面積の符号をそろえ、それぞれ成立する根拠を書く。
問題文から角B・高さなどの中間目標を消した。1つのSSA公式代入で終わらず、図形への戻しと完全な結論まで要求する。
